## Duplicaciones auditadas

No se fusionaron motores distintos a propósito:

- `data/enrichment.js` (`enrichProject`) aplica evidencias **al proyecto**. `enrichment/` cubre el **atlas**. Dominios distintos.
- `bitcoin.js` (unidades) vs `economics.js` (ENERGY × RATE): capas, no clones.
- `regional-validation.js` es la base; `validation/validate-region.js` la envuelve en el issue-bag.
- `ui/svg-*-view.js` son adaptadores del renderer canónico `svg/renderer.js`.
- `ui/architecture-graph.js` reexporta `graph/`.

Eliminado / cerrado en 16:

- Límite de tamaño ausente en import GeoJSON/CSV (hueco, no segundo parser).
- SW solo-push: ahora cachea el **shell** de la pestaña y **no** intercepta PDF ni tiles OSM.
- Mensaje de tiles genérico → warning honesto de red.
- Nav dispersa (toolbar + bottom tabs) → `wb-appnav` Atlas / Sitio / Workbench / Comparación / Reports / Enrichment / Proyecto.
- Deep links inexistentes → hash `#/atlas`, `#/map/:id`, `#/project/:id`, `#/snapshot/:id`, `#/compare/:id`.

No había report builders paralelos que calcularan potencia. HTML, PDF y comparison PDF leen el Report Model / comparison-view.

## Recorrido de cierre

1. Cargar proyecto (Start from zero / template / resume).
2. Elegir sitio (MAP, import GeoJSON o alta manual).
3. Ver arquitectura regionalizada (SYSTEM/SACRED + enrichment badge).
4. Comparar 2 opciones (Atlas checkboxes → Compare, o slots mixtos).
5. Descargar PDF con provenance. Cifras = Report Model; unknown = «Dato no disponible». Nadie gana en la comparación.

## Limitaciones honestas de v1

- Conceptual, no certificado, no grid-code compliance.
- Mapa: WGS84 + OSM; sin GIS de ingeniería; tiles requieren red.
- Enrichment: coverage media del atlas es parcial por diseño (unknown explícito).
- BTC: tarifa del modelo (ENERGY × BTC/kWh). El **spot CoinGecko** es un ticker informativo (`fiat/BTC`); no entra al motor, al PDF ni a la comparación hasta que se acepte como evidencia. Sin CDN de trading.
- Persistencia: un navegador, un origen. Borrar datos del sitio borra proyectos.
- Alpine se carga de jsDelivr (CSP lo permite). Offline total del JS de CDN no está garantizado la primera visita.
- Service Worker no sirve PDFs. Cache bust = `SW_VERSION` (`arch-v16`).
